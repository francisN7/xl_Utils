Política de Privacidade — xl_Utils

Última atualização: 8 de novembro de 2026.

O xl_Utils é um aplicativo desktop de código aberto para processar planilhas localmente. Ele não possui servidor próprio, não coleta telemetria e não envia seus arquivos ao desenvolvedor.

1. Dados que o app acessa

Sem a integração com o Google Drive, o app só lê os arquivos que você escolhe no seu computador.

Se você optar por entrar com o Google, o app solicita estes escopos:

  • openid e email: para identificar a conta (nome e e-mail).
  • https://www.googleapis.com/auth/drive.file: para ler e gravar apenas os arquivos do Drive que o app criar ou que você selecionar. O app não acessa o restante do seu Drive.

2. Como os dados são usados

Os dados são usados exclusivamente para executar as ferramentas que você escolher: ler a planilha, aplicar a regra e mostrar ou salvar o resultado. Não há publicidade, venda de dados, criação de perfis nem uso para treinar modelos.

3. Onde os dados ficam

  • Os arquivos processados ficam no seu computador, nas pastas que você indicar.
  • O refresh_token do Google fica em %LOCALAPPDATA%\xl_utils\drive\, cifrado com DPAPI (proteção do próprio Windows).
  • O identificador do cliente OAuth fica em %LOCALAPPDATA%\xl_utils\drive_client.json.
  • Nada disso é enviado ao desenvolvedor. O app não abre portas de rede além do retorno local do login (127.0.0.1).

4. Compartilhamento

O xl_Utils não compartilha, não vende e não transfere dados de usuários do Google para terceiros. O acesso ao Google Drive ocorre diretamente entre o seu computador e os servidores do Google, por HTTPS.

5. Retenção e exclusão

  • “Sair” no app apaga o token daquela conta no seu computador.
  • Você pode revogar o acesso do app a qualquer momento em myaccount.google.com/permissions.
  • Desinstalar o app ou apagar a pasta %LOCALAPPDATA%\xl_utils remove os dados locais.

6. Segurança

O login usa PKCE e state, o retorno é recebido em 127.0.0.1 numa porta efêmera e os tokens nunca aparecem em log, diagnóstico ou mensagem de erro. O token de atualização é cifrado com DPAPI e vinculado à sua conta do Windows.

7. Uso limitado dos dados do Google

O uso das informações recebidas das APIs do Google obedece à Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

8. Contato

Para dúvidas sobre privacidade, abra uma issue em github.com/francisN7/xl_Utils/issues ou use o e-mail de suporte informado na tela de consentimento do Google.
