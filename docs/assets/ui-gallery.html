Opção A — Sidebar + workspace

Barra lateral fixa com todas as ferramentas e um item “Início” para o painel de cartões. Cada ferramenta mantém estado ao alternar. É o modelo mais próximo de um app desktop e o mais rápido para uso repetido.

Minha recomendação: A com “Início”

A sidebar fixa dá velocidade e previsibilidade; o item “Início” entrega a descoberta do hub sem custo. A anatomia da ferramenta fica igual em todas as telas:

  • 1. Entrada — dropzone + seletor de arquivos, lista do que foi escolhido.
  • 2. Opções — só os controles que aquela ferramenta precisa.
  • 3. Resultado — status, caminho de saída, “Abrir pasta”, log e prévia opcional.
  • Barra de ação — botão primário sempre no mesmo lugar, com progresso e cancelamento.

O Dracula entra como tema único escuro: fundo #282A36, superfícies #44475A, primária #BD93F9, sucesso #50FA7B e erro #FF5555. O Flet permite isso via Theme(color_scheme=...) + ThemeMode.DARK.
